# Jay Keluskar — E-Waste Portfolio

This is a dependency-light, static portfolio intended for GitHub Pages.

## Keep this exact structure

Put these website files in the **same repository root** as the semester files:

- `index.html`
- all original uploaded task files, with their original names
- `Activity_Map_Of_EWASTE.jpeg`

No `src`, `public`, `assets`, npm install, Vite build, or React project structure is required.

## Publish on GitHub Pages

1. Push `index.html` and all task files to the `main` branch.
2. Open **Repository → Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.
6. Wait for GitHub Pages to publish the site.

If the repository is a project repository, the URL will normally be:
`https://<github-username>.github.io/<repository-name>/`

## Important

The portfolio links to the original filenames exactly. Do not rename the linked files unless you also update the corresponding `href` in `index.html`.

The LinkedIn link is intentionally not invented. Add the real URL when available.
